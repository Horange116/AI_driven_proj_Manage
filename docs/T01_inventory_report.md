## 5. 对 T02 的影响

T02 文件解析基线需要先按格式分流：

| 类别 | 扩展名 | 建议处理 |
|---|---|---|
| 优先解析 | `pdf`, `docx`, `xlsx` | 走 MinerU 或 Office 原生解析 |
| 需要兼容 | `doc`, `xls` | 评估 MinerU/Office 支持；必要时先转 `docx/xlsx/pdf` |
| 图片 OCR | `jpg`, `png` | 走图片/OCR 解析 |
| 工程附件 | `ai`, `dwg` | 先保留元数据和 hash，暂不做内容解析 |
| 归档文件 | `zip`, `rar` | 先作为资产记录，是否解包需要单独决策 |
| 非业务文件 | `scc`, `tmp` | 标记为低优先级或排除候选 |
